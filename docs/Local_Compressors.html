What has been integrated接入了什么

Two official text compressors now share one small interface. The compressor receives only context and a retained ratio. The evaluation question is added later by the unchanged API reader. No training is performed.两个官方文本压缩器现在共用一个小接口。压缩器只接收上下文和保留率，评测问题在之后才由原有 API reader 加入，不进行训练。

Use it in your experiment在实验中怎么用

Run from the repository root using its .venv Python. The input and output are ordinary strings. Create a separate instance for each method; the first creation loads its local model. Inference needs no API key.在仓库根目录使用 .venv 中的 Python 运行。输入和输出都是普通字符串；每个方法创建一个实例，首次创建时加载本地模型。压缩推理本身不需要 API key。

from blackwell.compressors import create_compressor

# Create once; reuse the loaded model across many contexts.
compressor = create_compressor("llmlingua2")
# Or: create_compressor("selective_context")

compressed_text = compressor.compress(
    "Alice booked a train to Paris on Friday. The booking was later cancelled.",
    retained_ratio=0.5,
)
print(compressed_text)  # str, not a probability or model object

Length conventions and fidelity长度约定与复现边界

retained_ratio always means the fraction to keep. Selective Context receives reduce_ratio = 1 − retained_ratio; LLMLingua-2 receives rate = retained_ratio. We keep the native output unchanged, count it using the same Qwen tokenizer as the reader, and mark outputs above the Qwen-token budget.retained_ratio 始终表示保留比例。Selective Context 收到 reduce_ratio = 1 − retained_ratio；LLMLingua-2 收到 rate = retained_ratio。原生输出不做二次截断，统一用 reader 的 Qwen tokenizer 计数，并标记超预算输出。

Thus equal nominal ratios do not imply equal lengths. Phrase filtering, word filtering and summarization allocate length differently. These pilot results cannot establish a fair matched-token winner. A later experiment should compare curves at matched measured budgets.因此名义比例相同不代表输出等长。短语筛选、词筛选、摘要的长度分配不同，本次结果不能确立严格等 token 预算下的优胜者。后续应按实际预算比较曲线。

Selective Context uses its published package code; only its model-loading hook is overridden for a pinned local safetensors model on CPU. Its old spaCy 3.2.0 / click 8.0.4 dependency pins are bypassed: the tested versions are recorded below. This is an official-implementation integration with modern dependency adaptation, not an exact reproduction of the original paper environment. Sentences exceeding GPT-2’s 1024-token limit fail explicitly.Selective Context 使用官方包源码，只覆盖模型加载钩子，使其加载固定的本地 safetensors 权重并在 CPU 运行。旧版 spaCy 3.2.0 / click 8.0.4 依赖锁定被绕过，实测版本见下表。这是适配现代依赖的官方实现接入，不是原论文环境的逐位复现。单句超过 GPT-2 的 1024-token 上限会明确报错。

LLMLingua-2 uses the dedicated second-generation method, with context-level filtering off and no forced question tokens or digit preservation. CPU float32, four PyTorch threads and a batch size of one keep this pilot portable. The reader remains Qwen3-30B-A3B-Instruct-2507 on SiliconFlow.LLMLingua-2 调用专属二代方法，关闭 context-level filtering，不强制保留问题词或数字。此 pilot 使用 CPU float32、4 个 PyTorch 线程、batch size 1。Reader 仍为硅基流动 Qwen3-30B-A3B-Instruct-2507。

blackwell/compressors/__init__.py
"""本地压缩器的统一入口；导入本包不会导入 PyTorch 或加载权重。"""

LOCAL_METHODS = ("selective_context", "llmlingua2")


def create_compressor(method):
    """只创建所选方法。返回对象的 compress(context, retained_ratio) 输出字符串。"""
    if method == "selective_context":
        from .selective_context import SelectiveContextCompressor
        return SelectiveContextCompressor()
    if method == "llmlingua2":
        from .llmlingua2 import LLMLingua2Compressor
        return LLMLingua2Compressor()
    raise ValueError(f"Unknown local compressor: {method}")


def validate_input(context, retained_ratio):
    if not isinstance(context, str):
        raise TypeError("context must be a string, not an example containing a question/label.")
    if isinstance(retained_ratio, bool) or not 0 < retained_ratio <= 1:
        raise ValueError("retained_ratio is the fraction to KEEP, in (0, 1].")
blackwell/compressors/selective_context.py
"""官方 selective-context 0.1.4 的薄封装：只替换固定版本的模型加载位置。"""
import re

from . import validate_input
from .runtime import model_directory, prepare_torch


class SelectiveContextCompressor:
    def __init__(self):
        prepare_torch()
        from selective_context import SelectiveContext
        from transformers import GPT2LMHeadModel, GPT2Tokenizer
        folder = str(model_directory("selective_context"))

        class PinnedSelectiveContext(SelectiveContext):
            def _prepare_model(self):
                # 保留官方句内 self-information、短语聚合与百分位筛选代码。
                # 覆盖此钩子，只为 CPU、safetensors、离线固定模型路径。
                self.device = "cpu"
                self.tokenizer = GPT2Tokenizer.from_pretrained(folder, local_files_only=True)
                self.model = GPT2LMHeadModel.from_pretrained(
                    folder, local_files_only=True, use_safetensors=True
                ).to(self.device).eval()
                self.max_token_length = self.model.config.n_positions
                self.get_self_information = self._get_self_info_via_gpt2

        self.engine = PinnedSelectiveContext(model_type="gpt2", lang="en")

    def compress(self, context, retained_ratio=0.5):
        """仅输入上下文和保留率，输出压缩文本；不接收 query。"""
        validate_input(context, retained_ratio)
        if not context.strip() or retained_ratio == 1:
            return context
        # 官方 GPT-2 按句计算，有 1024-token 位置上限。超长单句明确失败。
        clean = self.engine.beautify_context(context)
        for sentence in re.split(self.engine.sent_tokenize_pattern, clean):
            if sentence.strip():
                ids = self.engine.tokenizer.encode("<|endoftext|>" + sentence.strip(), add_special_tokens=False)
                if len(ids) > self.engine.max_token_length:
                    raise ValueError("Selective Context: a sentence exceeds GPT-2's 1024-token limit; no silent truncation.")
        # 注意：官方参数表示删去比例；本项目统一参数表示保留比例。
        text, _removed_phrases = self.engine(
            context, reduce_ratio=1 - retained_ratio, reduce_level="phrase"
        )
        return text
blackwell/compressors/llmlingua2.py
"""官方 llmlingua 0.2.2 的 LLMLingua-2 路径；不调用 LLMLingua-1。"""
from . import validate_input
from .runtime import model_directory, prepare_torch


class LLMLingua2Compressor:
    def __init__(self):
        torch = prepare_torch()
        from llmlingua import PromptCompressor
        self.engine = PromptCompressor(
            model_name=str(model_directory("llmlingua2")), device_map="cpu",
            model_config={"local_files_only": True, "trust_remote_code": False,
                          "torch_dtype": torch.float32},
            use_llmlingua2=True, llmlingua2_config={"max_batch_size": 1},
        )
        self.engine.model.eval()

    def compress(self, context, retained_ratio=0.5):
        """仅输入上下文和保留率，输出压缩文本；不接收 query。"""
        validate_input(context, retained_ratio)
        if not context.strip() or retained_ratio == 1:
            return context
        # 直接调用二代专属接口。此接口没有 question / instruction 参数。
        result = self.engine.compress_prompt_llmlingua2(
            context=[context], rate=retained_ratio, target_token=-1,
            use_context_level_filter=False, use_token_level_filter=True,
            token_to_word="mean", force_tokens=[], force_reserve_digit=False,
            drop_consecutive=False,
        )
        return result["compressed_prompt"]
blackwell/local_cache.py
"""缓存本地压缩结果；缓存身份只含 context、长度设置、模型和软件版本。"""
import time

from .compressors import create_compressor
from .storage import fingerprint, read_json, write_json


class LocalCompressionCache:
    def __init__(self, run_dir, identity, offline=False):
        self.directory = run_dir / "local_compression_cache"
        self.identity = identity
        self.offline = offline
        self.engines = {}

    def compress(self, context, budget, method, retained_ratio):
        request = {"context": context, "budget_tokens": budget, "method": method,
                   "retained_ratio": retained_ratio, "runtime": self.identity}
        key = fingerprint(request)
        path = self.directory / f"{key}.json"
        if path.exists():
            entry = read_json(path)
            if entry["request"] != request or entry["result_sha256"] != fingerprint(entry["result"]):
                raise ValueError("Local compression cache failed integrity checks.")
            return {**entry["result"], "local_compression_hash": key}
        if self.offline:
            raise RuntimeError("Offline local compression cache miss; inference is disabled.")
        if method not in self.engines:
            self.engines[method] = create_compressor(method)
        start = time.perf_counter()
        text = self.engines[method].compress(context, retained_ratio)
        if not isinstance(text, str):
            raise TypeError("Local compressor must return text.")
        result = {"text": text, "compression_seconds": time.perf_counter() - start,
                  "native_retained_ratio": retained_ratio}
        write_json(path, {"request": request, "result": result, "result_sha256": fingerprint(result)})
        return {**result, "local_compression_hash": key}
blackwell/compression.py
"""统一压缩接口：公共输入只有上下文、预算和方法名。"""
from .prompts import compression_messages
from .compressors import LOCAL_METHODS


class Compactor:
    def __init__(self, client, tokenizer, local_cache=None, retained_ratio=0.5):
        self.client = client
        self.tokenizer = tokenizer
        self.local_cache = local_cache
        self.retained_ratio = retained_ratio

    def compress(self, context, budget, method):
        """故意不接收 question、label 或原文预测，确保 query-blind。"""
        if method in LOCAL_METHODS:
            if self.local_cache is None:
                raise RuntimeError("Local compressor cache/runtime was not configured.")
            local = self.local_cache.compress(context, budget, method, self.retained_ratio)
            return {**self._result(local["text"], budget, [], False), **local}
        if method == "head_tail":
            text = self.tokenizer.head_tail(context, budget)
            return self._result(text, budget, [], False)
        if method != "summary":
            raise ValueError(f"Unknown compaction method: {method}")
        hashes = []
        previous = None
        previous_tokens = None
        for attempt in range(2):  # 最多一次长度修复；不根据预测效果挑摘要。
            messages = compression_messages(context, budget, previous, previous_tokens)
            text, request_hash = self.client.complete(
                messages, max_tokens=min(2048, max(256, budget * 3 + 100))
            )
            hashes.append(request_hash)
            count = self.tokenizer.count(text)
            if count <= budget:
                return self._result(text, budget, hashes, attempt == 1)
            previous, previous_tokens = text, count
        # 仍然超预算就明确标记并保留原输出，不偷偷追加截断策略。
        return self._result(previous, budget, hashes, True)

    def _result(self, text, budget, hashes, repaired):
        count = self.tokenizer.count(text)
        return {
            "text": text, "tokens": count, "budget_tokens": budget,
            "budget_met": count <= budget, "length_repair_used": repaired,
            "compression_request_hashes": hashes,
        }
