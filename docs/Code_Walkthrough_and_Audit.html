1 · What the experiment actually compares1 · 这个实验到底在比较什么

Research question: with the reader fixed, how does query-blind context compaction change the usefulness of its binary probability forecasts?研究问题：固定 reader 后，不看后续 query 的上下文压缩，会怎样改变其二元概率预测的决策价值？

Passage X → {Full, No context, Head+tail, Summary} → Same reader + Question Q → p(Yes) → Join gold label y → InfoGap in both directions段落 X → {原文、空上下文、首尾截断、摘要} → 同一 reader + 问题 Q → p(Yes) → 接入真实标签 y → 双向 InfoGap

A forecast p describes the distribution (P(No), P(Yes)) = (1−p, p). The model is asked to state p directly in JSON. We do not equate that number with a true Bayesian posterior, and we do not claim to recover the model’s internal beliefs.一个概率 p 即可表示分布 (P(No), P(Yes)) = (1−p, p)。模型直接用 JSON 报告 p。我们不把这个数预设为真实贝叶斯后验，也不声称恢复了模型内部的真实信念。

The comparison concerns compactor + fixed reader + elicitation prompt on BoolQ. The reader may use background knowledge; the no-context control helps reveal this. Higher confidence alone does not imply higher informativeness.比较对象是 BoolQ 上的“压缩器 + 固定 reader + 概率提取提示词”。Reader 可以使用背景知识，无上下文对照帮助观察这一点。置信度更高本身不代表更有信息。

5 · InfoGap, step by step5 · InfoGap 怎样算

h_t(p, y) = max(t − p, 0) + (p − y) × 1[p ≤ t]
          = (t − y) × 1[p ≤ t]

D_AB(t) = (1/n) Σ_i [h_t(p_i^A, y_i) − h_t(p_i^B, y_i)]
G_hat(A, B) = 2 × sup_{t∈[0,1]} D_AB(t)

For a candidate threshold t, evaluate the same decision rule for both forecast sets against the same labels. Search over all thresholds for the largest advantage of A. Reversing A and B answers a different question. The formula does not merely measure |pA−pB| or KL divergence.对候选阈值 t，两组预测使用相同决策规则、相同真实标签评估。遍历阈值寻找 A 的最大优势。交换 A 和 B 是另一个问题。这不是只计算 |pA−pB| 或 KL 散度。

D is linear between consecutive observed probabilities, but can jump at those probabilities when forecasts are miscalibrated. The event-scan algorithm checks every breakpoint before and after adding tied observations. It also includes 0 and 1. The saved side identifies a left limit versus the value at a threshold.D 在相邻预测概率之间是线性的，但失校准时会在概率断点处跳跃。事件扫描在每个断点计入相同概率样本之前和之后各计算一次，也包含 0 和 1。保存的 side 区分左极限和阈值处的值。

Version convention: Theorem 4.1 and the proof of Theorem 5.1 in arXiv:2507.12094v2 use factor 2. The estimator displayed in Theorem 5.1 omits it. This code follows the former and stores both scaled value and unscaled. This discrepancy still requires confirmation against the authors’ final version.版本约定：arXiv:2507.12094v2 的定理 4.1 及定理 5.1 证明含系数 2，定理 5.1 展示的 estimator 未写 2。代码采用前者，并同时保存 value 与 unscaled。该差异仍需对照作者最终版本确认。

Sanity example: gold labels [0,1], perfect forecasts [0,1], uninformative forecasts [0.5,0.5]. G(perfect, uninformative)=0.5; reverse=0. Tests independently compute actual utility differences for two-action decision problems, rather than only repeating the estimator’s implementation.手算检查：标签 [0,1]，完美预测 [0,1]，无信息预测 [0.5,0.5]。G(完美, 无信息)=0.5，反向为 0。测试还独立计算两动作决策的实际收益差，而不是仅重复估计器代码。

We do not calibrate forecasts first. We retain probabilities at their original precision. True labels are necessary: prediction-only access in this paper still supplies prediction–label pairs.不先对概率做校准；保留原始数值精度。真实标签仍然必要：论文的 prediction-only access 仍提供“预测—标签”样本对。

6 · Supporting metrics and uncertainty6 · 辅助指标与不确定性

Brier = mean((p − y)^2)
Log loss = −mean[y log(p) + (1−y) log(1−p)]
Accuracy = mean(1[(p ≥ 0.5) == y])

Only log loss clips p to [10⁻¹², 1−10⁻¹²] to avoid log(0). InfoGap and Brier use the original values. Accuracy loses probability information and remains a supporting result, not the main comparison.仅 Log loss 为避免 log(0)，把 p 限定到 [10⁻¹², 1−10⁻¹²]。InfoGap 与 Brier 使用原值。Accuracy 会丢失概率信息，所以只作为辅助结果。

We draw paired bootstrap samples, grouping duplicate passages together. The 2.5%–97.5% ranges describe instability in this pilot. Because the statistic is a supremum and n is small, these are not a justified test of population Blackwell dominance. More data, multiple readers and a separate inference protocol are needed for paper-level claims.对样本做配对 bootstrap，相同 passage 成组抽样。2.5%–97.5% 范围描述 pilot 的波动。由于统计量是 supremum 且 n 很小，这些区间不能作为总体 Blackwell 支配的可靠检验。论文级结论还需要更大样本、多个 reader 和单独设计的统计推断协议。

Limits: short contexts; small n; a single relatively small reader; verbalized probabilities can be coarse and miscalibrated; model-serving aliases can change; BoolQ may overlap pretraining data; one question per item does not establish query-universal informativeness. The scalar metrics do not recover a true posterior.局限：上下文较短、n 很小、只有一个较小的 reader；直接报告的概率可能粗糙且失校准；服务商模型别名可能更新；BoolQ 可能与预训练数据重叠；每条样本一个问题无法证明对所有 query 的 informativeness。标量指标不能恢复真实后验。

Keep those as new, separately named experiments rather than retroactively changing this pilot.下一步适合加入 HotpotQA 原生 yes/no、一个更强的固定 reader，以及已发表的 query-agnostic 压缩方法。都应另建实验编号，不回头改写这次 pilot。

005  class Compactor:
006      def __init__(self, client, tokenizer):
007          self.client = client
008          self.tokenizer = tokenizer
009
010      def compress(self, context, budget, method):
011          """故意不接收 question、label 或原文预测，确保 query-blind。"""
012          if method == "head_tail":
013              text = self.tokenizer.head_tail(context, budget)
014              return self._result(text, budget, [], False)
015          if method != "summary":
016              raise ValueError(f"Unknown compaction method: {method}")
017          hashes = []
018          previous = None
019          previous_tokens = None
020          for attempt in range(2):  # 最多一次长度修复；不根据预测效果挑摘要。
021              messages = compression_messages(context, budget, previous, previous_tokens)
022              text, request_hash = self.client.complete(
023                  messages, max_tokens=min(2048, max(256, budget * 3 + 100))
024              )
025              hashes.append(request_hash)
026              count = self.tokenizer.count(text)
027              if count <= budget:
028                  return self._result(text, budget, hashes, attempt == 1)
029              previous, previous_tokens = text, count
030          # 仍然超预算就明确标记并保留原输出，不偷偷追加截断策略。
031          return self._result(previous, budget, hashes, True)
032
033      def _result(self, text, budget, hashes, repaired):
034          count = self.tokenizer.count(text)
035          return {
036              "text": text, "tokens": count, "budget_tokens": budget,
037              "budget_met": count <= budget, "length_repair_used": repaired,
038              "compression_request_hashes": hashes,

001  """InfoGap 核心数学：不依赖 LLM、tokenizer 或网络，可单独审计。"""
002  import math
003  import random
004  from collections import defaultdict
005

007  def _validate(probabilities, labels):
008      if not probabilities or len(probabilities) != len(labels):
009          raise ValueError("Nonempty, equal-length prediction and label arrays are required.")
010      if any(type(p) not in {int, float} or not math.isfinite(p) or not 0 <= p <= 1 for p in probabilities):
011          raise ValueError("Probabilities must be finite numbers in [0, 1].")
012      if any(type(y) not in {int, bool} or y not in {0, 1} for y in labels):
013          raise ValueError("Labels must be binary.")
014

016  def infogap(probabilities_a, probabilities_b, labels):
017      """估计 G(A,B)：A 相对 B 的最大决策收益优势，通常不对称。
018
019      h_t(p,y) = (t-p)_+ + (p-y) 1[p<=t] = (t-y) 1[p<=t]
020      G(A,B) = 2 sup_t mean(h_t(p_A,y) - h_t(p_B,y)).
021
022      系数 2 采用 arXiv:2507.12094v2 定理 4.1 和定理 5.1 的证明；
023      定理 5.1 展示的 estimator 漏写/采用不同尺度，故同时保存 unscaled。
024      在全部概率断点及左右极限求 supremum，不使用粗网格或四舍五入。
025      """
026      _validate(probabilities_a, labels)
027      _validate(probabilities_b, labels)
028      # 对每个概率断点，记录通过该点时线性函数 D(t)=slope*t+intercept 的变化。
029      events = defaultdict(lambda: [0, 0])
030      for a, b, y in zip(probabilities_a, probabilities_b, labels):
031          events[a][0] += 1
032          events[a][1] -= y
033          events[b][0] -= 1
034          events[b][1] += y
035      events[0.0]
036      events[1.0]
037      slope, intercept = 0, 0
038      best = {"unscaled": 0.0, "threshold": 0.0, "side": "constant_action"}
039      n = len(labels)
040      for threshold in sorted(events):
041          # 在断点左边，尚未计入 p==threshold 的样本。
042          if threshold > 0:
043              value = (slope * threshold + intercept) / n
044              if value > best["unscaled"]:
045                  best = {"unscaled": value, "threshold": threshold, "side": "left_limit"}
046          slope += events[threshold][0]
047          intercept += events[threshold][1]
048          # 此处实现论文的 <= 约定；允许概率完全相同或等于 0/1。
049          value = (slope * threshold + intercept) / n
050          if value > best["unscaled"]:
051              best = {"unscaled": value, "threshold": threshold, "side": "at_threshold"}
052      return {"value": 2 * best["unscaled"], **best, "n": n, "normalization_factor": 2}
053
054
055  def forecast_scores(probabilities, labels):
056      _validate(probabilities, labels)
057      n = len(labels)
058      # 仅 Log loss 使用 clipping；InfoGap、Brier 和原始输出均不改概率。
059      clipped = [min(1 - 1e-12, max(1e-12, p)) for p in probabilities]
060      return {
061          "accuracy": sum(int(p >= 0.5) == y for p, y in zip(probabilities, labels)) / n,
062          "brier": sum((p - y) ** 2 for p, y in zip(probabilities, labels)) / n,
063          "log_loss": -sum(y * math.log(p) + (1 - y) * math.log(1 - p) for p, y in zip(clipped, labels)) / n,
064      }

067  def bootstrap_gaps(a, b, labels, groups, repetitions=500, seed=20261017):
068      """按上下文成组、两方法配对重采样；区间仅描述 pilot 波动，不证明支配。"""
069      _validate(a, labels)
070      _validate(b, labels)
071      if len(groups) != len(labels) or repetitions < 2:
072          raise ValueError("Invalid bootstrap settings.")
073      members = defaultdict(list)
074      for index, group in enumerate(groups):
075          members[group].append(index)
076      keys = list(members)
077      rng = random.Random(seed)
078      draws_ab, draws_ba = [], []
079      for _ in range(repetitions):
080          indices = [i for group in rng.choices(keys, k=len(keys)) for i in members[group]]
081          sampled_a = [a[i] for i in indices]
082          sampled_b = [b[i] for i in indices]
083          sampled_y = [labels[i] for i in indices]
084          draws_ab.append(infogap(sampled_a, sampled_b, sampled_y)["value"])
085          draws_ba.append(infogap(sampled_b, sampled_a, sampled_y)["value"])
086
087      def interval(values):
088          values = sorted(values)
089          return [values[int(0.025 * (len(values) - 1))], values[int(0.975 * (len(values) - 1))]]
090
091      return {"a_over_b": interval(draws_ab), "b_over_a": interval(draws_ba),
092              "repetitions": repetitions, "context_clusters": len(keys),
093              "interpretation": "Descriptive paired cluster-bootstrap percentile interval, not a dominance test."}

013  class CachedChatClient:
014      def __init__(self, config, run_dir, offline=False):
015          self.config = config
016          self.run_dir = run_dir
017          self.offline = offline
018          self.cache_dir = run_dir / "api_cache"
019          self.cache_dir.mkdir(parents=True, exist_ok=True)

021          self.ledger = read_json(self.ledger_path) if self.ledger_path.exists() else []
022          self.last_call = 0.0
023          self.new_attempts = 0
024          self.cache_hits = 0

026      def complete(self, messages, max_tokens, json_mode=False):
027          payload = {
028              "model": self.config["model"], "messages": messages,
029              "temperature": self.config["temperature"], "max_tokens": max_tokens,
030              "enable_thinking": self.config["enable_thinking"], "stream": False,
031          }
032          if json_mode:
033              payload["response_format"] = {"type": "json_object"}
034          identity = {"base_url": self.config["base_url"], "payload": payload}
035          request_hash = fingerprint(identity)
036          cache_path = self.cache_dir / f"{request_hash}.json"
037          if cache_path.exists():
038              self.cache_hits += 1
039              record = read_json(cache_path)
040              if record["request"] != identity:
041                  raise ValueError("Cache content does not match the requested input.")
042              return self._extract(record["response"], request_hash)
043          if self.offline:
044              raise RuntimeError("Offline replay is missing a cached response. No API call was made.")
045          key = os.environ.get(self.config["api_key_env"], "").strip()
046          if not key:
047              raise RuntimeError(f"Set the environment variable {self.config['api_key_env']} first.")
048
049          # 只对网络错误、限流、服务端错误重试；参数/认证错误立即停止。
050          for attempt in range(3):
051              retry_delay = 2 ** (attempt + 1)
052              if len(self.ledger) >= self.config["max_api_attempts"]:
053                  raise RuntimeError("Hard API-attempt limit reached; stopped before the next request.")
054              wait = self.config["min_interval_seconds"] - (time.monotonic() - self.last_call)
055              if wait > 0:
056                  time.sleep(wait)
057              entry = {
058                  "request_hash": request_hash, "status": "started",
059                  "started_utc": datetime.now(timezone.utc).isoformat(),
060                  "max_output_tokens": max_tokens,
061              }
062              # 先记账后发送，即使请求超时也计入调用上限。
063              self.ledger.append(entry)
064              write_json(self.ledger_path, self.ledger)
065              self.new_attempts += 1
066              request = Request(
067                  self.config["base_url"].rstrip("/") + "/chat/completions",
068                  data=json.dumps(payload, ensure_ascii=False, allow_nan=False).encode("utf-8"),
069                  headers={"Authorization": f"Bearer {key}", "Content-Type": "application/json"},
070                  method="POST",
071              )
072              self.last_call = time.monotonic()
073              try:
074                  with urlopen(request, timeout=self.config["timeout_seconds"]) as response:
075                      body = json.load(response)
076                  entry["status"] = "received"
077                  entry["usage"] = body.get("usage", {})
078                  write_json(self.ledger_path, self.ledger)
079                  write_json(cache_path, {
080                      "request": identity, "response": body,
081                      "received_utc": datetime.now(timezone.utc).isoformat(),
082                  })
083                  return self._extract(body, request_hash)
084              except HTTPError as error:
085                  entry.update(status="http_error", http_status=error.code)
086                  write_json(self.ledger_path, self.ledger)
087                  if error.code not in {429, 500, 502, 503, 504} or attempt == 2:
088                      # 不输出响应正文/请求头，避免服务端错误信息意外包含凭证。
089                      raise RuntimeError(f"API returned HTTP {error.code}; see api_attempts.json.") from None
090                  if error.code == 429:
091                      # 免费端点的每分钟限额较低；不以密集重试加重限流。
092                      retry_delay = 15 * (attempt + 1)
093              except (URLError, TimeoutError) as error:
094                  entry.update(status="network_error", error_type=type(error).__name__)
095                  write_json(self.ledger_path, self.ledger)
096                  if attempt == 2:
097                      raise RuntimeError("API connection failed after three attempts.") from None
098              time.sleep(retry_delay)
099          raise RuntimeError("No API response.")

012      def __init__(self):
013          self.path = download(
014              TOKENIZER_URL, ROOT / "data" / "tokenizer" / "qwen3-30b-a3b-instruct-2507.json", TOKENIZER_SHA256
015          )
016          self.tokenizer = Tokenizer.from_file(str(self.path))

018      def count(self, text):
019          # 不包括 system prompt、问题或 chat template；API usage 另行记录。
020          return len(self.tokenizer.encode(text, add_special_tokens=False).ids)
021
022      def head_tail(self, text, budget):
023          """按 token 分配首尾额度，但在字符边界截取，避免切坏 Unicode。"""
024          encoded = self.tokenizer.encode(text, add_special_tokens=False)
025          if len(encoded.ids) <= budget:
026              return text
027          left = (budget + 1) // 2
028          right = budget // 2
029          while left or right:
030              prefix = text[:encoded.offsets[left - 1][1]] if left else ""
031              suffix = text[encoded.offsets[-right][0]:] if right else ""
032              candidate = prefix + ("\n[...]\n" if left and right else "") + suffix
033              # 截断标记也占预算；拼接后重新计数，而非假设 token 数可相加。
034              if self.count(candidate) <= budget:
035                  return candidate
036              if left >= right:
037                  left -= 1
038              else:
039                  right -= 1
040          return ""

035  def download(url, path, expected_sha256=None):
036      """只下载明确指定的公开数据或 tokenizer；不下载模型权重。"""
037      path = Path(path)
038      if not path.exists():
039          path.parent.mkdir(parents=True, exist_ok=True)
040          request = Request(url, headers={"User-Agent": "Blackwell-Compaction/0.1"})
041          with urlopen(request, timeout=90) as response:
042              content = response.read()
043          if expected_sha256 and hashlib.sha256(content).hexdigest() != expected_sha256:
044              raise ValueError("Downloaded file has an unexpected SHA-256.")
045          temporary = path.with_suffix(path.suffix + ".download")
046          temporary.write_bytes(content)
047          os.replace(temporary, path)
048      if expected_sha256 and file_hash(path) != expected_sha256:
049          raise ValueError(f"File checksum mismatch: {path.name}")
050      return path

008  def decision_payoff_gap(a, b, labels, threshold):
009      """独立核验：两动作的实际收益，不调用 h_t 或事件扫描算法。"""
010      def utility(p, y):
011          return threshold - y if p <= threshold else y - threshold
012      return sum(utility(pa, y) - utility(pb, y) for pa, pb, y in zip(a, b, labels)) / len(labels)
