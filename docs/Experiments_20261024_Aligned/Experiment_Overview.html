What changed本轮改进

Eight paired conditions; all forecasts were collected anew. The target cap is floor(0.5 × original Qwen tokens). The preferred band is 95–100% of this cap (about 47.5–50% of the original). Local methods use at most eight length-only native-rate trials. The formal baselines use one API rewrite per unique context and method; optional length-repair drafts are supported in code but disabled here. Final equality is enforced by the separate common-length step. A draft within the target band is preferred; otherwise select the closest measured length, favoring feasible drafts at ties. A selected overshoot is clamped with a common head–tail adapter and explicitly counted. Underfilled outputs are kept and reported; no padding, gold-based selection or silent sample removal.共八组配对输入，全部重新获取预测。共同上限为 floor(0.5×原文 Qwen tokens)，目标区间是上限的 95%–100%，约等于原文的 47.5%–50%。本地方法最多尝试八个原生保留率，只看长度；正式 baseline 每种方法对每份独立上下文只改写一次；代码保留可选的长度修订能力，本轮关闭。最终等长由单独的共同长度步骤保证。优先选目标区间内候选，否则选实测长度距预算最近者，同距时优先不超长；选中超长稿则使用共同首尾裁剪并明确计数。填不满的结果保留且报告，不补无意义内容，不用答案选候选，不悄悄删题。

For the primary comparison, each context is then matched to the shortest feasible output among the six compressed conditions. Longer outputs are deterministically trimmed until their actual Qwen token counts are exactly equal. Full and no-context controls are unchanged. Local native algorithms are not rerun at this lower common budget: this experiment compares compressor-plus-trimming compositions, not native algorithms optimized directly for that budget. The common budget can be below 50% and varies by context; no query or label is used to choose it. Read the actual-length distribution, underfill and clamp counts alongside InfoGap. Summary and Telegrapher both use DeepSeek-V3.2 as the rewrite model; the reader remains Qwen3-30B-A3B-Instruct-2507. Rewrite requests contain no query. Telegrapher uses the pinned official v5 grammar with an explicit budget instruction; full-document input, DeepSeek deployment and length repairs are adaptations, not the original paper configuration.主比较还会按每份上下文在六种压缩条件中取最短可行长度，将更长输出确定性裁剪到实际 Qwen token 数完全相同。原文和空上下文对照不变。本轮不会在更低的共同预算下重跑原生算法，因此比较的是“压缩器＋裁剪”的组合，不是原生算法直接针对该低预算优化的表现。共同预算可能低于 50%，因上下文而异，确定它不使用 query 或标签。解读 InfoGap 时应同时查看实际长度分布、欠填和裁剪次数。摘要与 Telegrapher 均用 DeepSeek-V3.2 改写，reader 保持 Qwen3-30B-A3B-Instruct-2507；改写请求不含 query。Telegrapher 使用固定官方 v5 语法及额外预算指令；全文输入、DeepSeek 部署和长度修订属于适配，并非论文原配置。

Compression receives only context and budget. The reader alone receives the evaluation question; labels are used only during evaluation. Shared paper contexts reuse the same compression. All six compressed conditions have the same token count per question, including the head–tail control. The 458 HotpotQA / 283 QASPER-train / 52 LongBench binary examples and order are frozen from the old runs. LongBench is a native binary subset, not its official full benchmark; 14 questions overlap HotpotQA and one overlaps QASPER train.压缩只接收 context 与预算；只有 reader 接收评测问题，标签只用于评估。同篇论文复用同一压缩文本。包括首尾截断在内的六种压缩条件在每题上 token 数完全相同。458 道 HotpotQA、283 道 QASPER train、52 道 LongBench 二元题沿用旧样本及顺序。LongBench 为原生二元子集，并非官方完整 benchmark；其中 14 题与 HotpotQA 重叠，1 题与 QASPER train 重叠。

Only complete API rewrites are accepted. An output-limit response triggers at most one identical-prompt retry with a larger output ceiling (maximum 32768); truncated text is excluded. Raw responses and attempts remain recorded. Reader forecasts are strictly parsed without this retry. Validated cache reuse and original compute times are recorded in each v2 run’s cache_reuse_provenance.json; previous runs are preserved.仅接受完整 API 改写。输出上限截断最多触发一次相同提示词、提高输出上限的重试（最多 32768），截断文本不参与实验。原响应及尝试次数均留存。reader 概率严格解析且不使用此重试。v2 的 cache_reuse_provenance.json 记录经核验的缓存复用和原计算时间；旧运行全部保留。

All breakpoints and left limits are evaluated. Both scaled and unscaled values are saved. These are verbalized forecasts, not verified Bayesian posteriors.
