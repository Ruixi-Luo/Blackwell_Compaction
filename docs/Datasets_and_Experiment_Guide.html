There are 7,405 dev items in the pinned distractor file. We keep only native answers yes/no, without balancing labels. All 458 eligible items are comparison questions. Of these, 447 provide 10 paragraphs and 11 provide 2–9. All supplied paragraphs and titles are retained in their original order; no gold evidence selection or question-based reordering is performed.固定版本的 distractor dev 共 7,405 题，只筛原生 yes/no 答案，不平衡标签。458 道入选题全部为 comparison 类：447 道有 10 段，11 道有 2–9 段。保留全部所提供段落及标题和原始顺序，不按 gold evidence 筛选，不用问题重排。

This is roughly 1.2k-token context, longer than the previous BoolQ pilot, but not a 4k–16k long-context benchmark. The context retrieval was question-conditioned during dataset construction; only our compression step is query-blind. Results apply to this binary comparison subset, not all HotpotQA questions.这里约为 1.2k token 上下文，比此前的 BoolQ 长，但尚不属于 4k–16k 的长上下文评测。数据集构造时的检索依赖问题，只有我们的压缩环节是 query-blind。结果适用于该二元 comparison 子集，不能代表全部 HotpotQA。

QASPER: what is actually usable?QASPER：究竟有多少可用样本？

The counting unit is a question, not an answer annotation. Strict eligibility requires a nonempty body, at least one annotation, every annotation classified as boolean by the official evaluator precedence, and unanimous yes/no labels. Unanswerable takes precedence; false means No, whereas null is missing. No majority vote or first-annotation shortcut is used.计数单位是问题，不是答案标注。严格入选要求正文非空、至少一份标注、全部标注按官方 evaluator 优先级都属于 boolean，且 yes/no 一致。unanswerable 优先，false 表示 No，null 才是缺失。不用多数投票或第一份答案代替一致性检查。

The more conservative text-verified subset requires nonempty evidence in every annotation, no FLOAT SELECTED figure/table marker, and every evidence passage present in the proposed full-text input after whitespace normalization. This is an additional experiment-design filter, not an official QASPER split. It does not certify annotation correctness or complete PDF extraction.更保守的文字证据子集要求每份标注 evidence 非空、无 FLOAT SELECTED 图表标记，且所有证据段落在规范空白后的全文输入中都能找到。这是额外实验设计筛选，不是官方 QASPER 划分，也不能保证标注正确或 PDF 抽取完整。

The conservative filter removes many No questions whose evidence is empty, shifting the label distribution. Therefore both counts are retained: do not describe the conservative subset as an unbiased sample, and do not equate No with unanswerable.保守筛选会排除许多 evidence 为空的 No 问题，从而改变标签比例。因此同时保留两套统计：不能把保守子集称为无偏样本，也不能把 No 当作 unanswerable。

A loader returns a list of plain dictionaries with context, question, label, id and context_group, plus provenance. Compression is deliberately called with context only, never the whole dictionary. A new dataset needs a small loader and one dispatch entry; do not rewrite the reader or InfoGap. The reader remains deliberately restricted to the verified SiliconFlow/Qwen configuration.Loader 返回普通字典列表（context、question、label、id、context_group 等）和来源记录。压缩只接收 context，不接收整个字典。新增数据只需一个小 loader 和入口注册，不重写 reader 或 InfoGap。Reader 目前仍明确限制为已验证的硅基流动/Qwen 组合。

Run and audit it yourself自己运行与审计

# Run from the repository root. All caches stay on D:.
$env:PIP_CACHE_DIR = "$PWD/.cache/pip"
$env:TEMP = "$PWD/.cache/tmp"; $env:TMP = $env:TEMP
.\.venv\Scripts\python.exe -m pip install -r requirements-data.txt
.\run.ps1 -Mode Test
.\run.ps1 -Mode Prepare -Config configs/hotpotqa.json
# Calls the paid reader on cache misses; 30 × 4 forecasts, maximum 150 attempts.
.\run.ps1 -Mode Run -Config configs/hotpotqa.json
.\run.ps1 -Mode Audit -Config configs/hotpotqa.json
.\.venv\Scripts\python.exe tools/check_local_chunking.py --config configs/hotpotqa.json
.\.venv\Scripts\python.exe tools/verify_offline_replay.py --config configs/hotpotqa.json
# QASPER inventory only; no LLM calls. Omit --offline for the first download.
.\.venv\Scripts\python.exe tools/inspect_datasets.py --offline
# Two-item BoolQ quick check, no local compressor weights required.
.\run.ps1 -Mode Run -Config configs/quickcheck.json

Run setup.ps1 first on a new clone, and setup-local.ps1 once for local compressor weights. Old runs are preserved. Changing code, configuration or data requires a new run_name; reports can still be recomputed from old predictions. Strict replay requires the corresponding source version. Raw datasets, environments and API caches remain ignored by Git.新克隆先运行 setup.ps1，本地压缩器额外运行一次 setup-local.ps1。旧实验全部保留。修改代码、配置或数据要换 run_name；旧预测仍可重算报告，严格重放需匹配源码版本。原始数据、环境及 API 缓存均不进入 Git。
