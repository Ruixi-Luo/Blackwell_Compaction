Protocol实验设置

Reader: Qwen3-30B-A3B-Instruct-2507. Summary writer: DeepSeek-V3.2. Temperature 0; thinking disabled; one verbalized p(Yes) per question and condition. The API returns a probability JSON, not token-logprob-derived or calibrated posteriors.Reader：Qwen3-30B-A3B-Instruct-2507；摘要模型：DeepSeek-V3.2。temperature=0，关闭 thinking；每题每条件一次口头概率 p(Yes)。这些数值并非由 token logprob 推导或已经校准的后验。

Each source receives B=floor(0.5 × original Qwen tokens) before compression. The summary always uses the first verified complete original-prompt generation, even when it exceeds B. No later candidate is selected, and questions, labels or prediction scores do not affect the choice. No shortest-output matching, post-truncation, label feedback or query input is allowed.压缩前按原文确定 B=floor(0.5 × 原文 Qwen tokens)，摘要一律使用原始提示词的第一份完整生成结果，即使超出 B 也保留，不选择后续候选，不参考问题、标签或预测效果；不向最短输出对齐，不事后截断，不使用标签反馈，也不向压缩器传 query。

HotpotQA: 100 native yes/no distractor-dev questions (45 Yes / 55 No). QASPER: 100 consistent, text-evidence yes/no train questions from 97 papers (71 Yes / 29 No). Samples are uniformly drawn from the previously defined pools with seed 20261025, without outcome filtering. This is an exploratory subset; QASPER train is not a held-out test.HotpotQA：distractor dev 原生 yes/no 随机 100 题，45 Yes／55 No。QASPER：train 中标签一致、证据可在正文找到的 yes/no 随机 100 题，来自 97 篇论文，71 Yes／29 No。从先前定义的样本池以种子 20261025 均匀抽样，不按模型结果筛选。这是探索性子集，QASPER train 不是独立测试集。

Prompt controls and summary provenancePrompt 控制与摘要来源

The reader system prompt, question wrapper, model and generation parameters are unchanged across conditions; only context text changes. All 197 summary inputs are the original first complete generations from one common prompt template (with source-specific lengths), without output-ceiling retries or length revisions. They cover 200 questions. All compressor requests are query-blind; history is reused rather than regenerated.各条件共享未改动的 reader system prompt、问题包装、模型与生成参数，仅改变上下文文本。197 份摘要全部是同一原始提示词模板（按原文长度填写预算）的首次完整生成，没有提高输出上限重试，也没有长度修订，覆盖 200 题。所有压缩请求均不含 query；这些历史生成结果直接复用。

Interpretation and limits解释与边界

The tested object is a compressor-plus-fixed-reader pipeline on a particular question distribution. Raw p(Yes) may be miscalibrated; confidence shifts can change InfoGap even without better factual retention. These results do not establish a query-agnostic Blackwell ordering of compressed text.评测对象是特定问题分布下的“压缩器＋固定 reader”。原始 p(Yes) 可能失准；置信度变化也会改变 InfoGap，并不必然代表事实保留更好。本实验不能建立压缩文本本身 query-agnostic 的 Blackwell 排序。

DAC uses the official dynamic attention + information-score selection (10 iterations, α=0.8), with a full-context blocked attention reduction and blocked vocabulary logits for 8GB GPU memory. Two short examples matched the official compressed text exactly; the complete longest selected source (16,755 tokens) passed at a 3.25 GiB peak. No source tokens were truncated. Floating-point reductions can differ slightly from the reference implementation.DAC 使用官方动态注意力＋信息量筛选（10 次迭代，α=0.8）；为适配 8GB 显存，完整上下文注意力与词表 logits 分块计算。两份短样例与官方压缩文本完全一致；最长 16,755 tokens 完整输入通过，峰值约 3.25 GiB。没有截掉原文；浮点累加顺序仍可能产生微小数值差异。

Historical outputs are reused only for identical complete reader requests. Summary drafts are reused from historical source-only requests; no new summary generation is needed for this first-draft protocol. Local compressor outputs are reused unchanged. The summary input is a one-shot baseline, while local compressors retain their previous length adaptation. Computational effort is not matched, and collection dates span historical and current requests. All 1,200 probabilities, compression lengths and 72 InfoGap cells passed the audit; old result files were hash-checked unchanged.历史预测仅在完整 reader 请求一致时复用。摘要复用历史上仅含原文和旧草稿的请求，本次第一稿方案不再生成摘要；本地压缩输出原样复用。摘要输入是单次生成基线，本地方法则保留此前的长度适配；计算量并未对齐，数据收集也跨越历史与当前请求。1,200 条概率、压缩长度和 72 个 InfoGap 单元格通过审计，旧结果文件哈希保持不变。
