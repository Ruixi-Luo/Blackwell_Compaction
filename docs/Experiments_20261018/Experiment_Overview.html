How to read the experiment如何阅读实验

G(Full, C) is the largest empirical decision-payoff advantage of full context over compressor C; G(C, Full) measures the reverse advantage. Both may be positive. Brier and log loss evaluate probabilistic forecasts; accuracy uses a 0.5 threshold. A nominal 50% retention setting does not imply equal realized token budgets.G(原文,C) 是原文相对压缩方法 C 的最大经验决策收益优势，G(C,原文) 衡量反向优势；两者可能同时大于零。Brier 和 log loss 评价概率预测，Accuracy 使用 0.5 阈值。名义保留率相同，不代表实际 token 预算相同。

HotpotQA is the larger multi-paragraph pilot, not a long-context benchmark. QASPER uses full papers from train and a conservative text-evidence filter (192 Yes / 91 No); dev/test are reserved. LongBench is a 52-item binary subset of the standard English release; its pooled number describes this task mixture, not the official full benchmark. Dataset results remain separate.HotpotQA 是样本较多的多段落探索实验，不是长上下文 benchmark。QASPER 使用 train 全文及保守的文字证据筛选（192 Yes / 91 No），dev/test 保留。LongBench 是标准英文版的 52 题二元子集，其汇总值描述该任务混合，不是官方完整 benchmark 分数。各数据集分别报告。

All numbers use one fixed API reader and its verbalized p(Yes), not verified Bayesian posteriors. Compressors never receive questions or labels. InfoGap is a normalized payoff gap, not bits or a percentage of information retained. The experiment measures forecast usefulness on these question distributions; it does not prove universal Blackwell informativeness of the compressed text.所有结果使用同一个 API reader 直接报告的 p(Yes)，不预设为真实贝叶斯后验。压缩器看不到问题或标签。InfoGap 是归一化的收益差，不是比特数或信息保留百分比。本实验测量这些问题分布下的预测价值，不能证明压缩文本对所有未来问题的 Blackwell 信息性。

Metric definitions指标计算方法

Brier = mean((p_yes − y)²)
Log loss = −mean(y log(p_yes) + (1−y) log(1−p_yes))
Accuracy = mean(1[p_yes ≥ 0.5] = y)
G(A,B) = 2 sup_t mean((t−y)(1[p_A ≤ t] − 1[p_B ≤ t]))
Retained ratio = sum(compressed Qwen tokens) / sum(original Qwen tokens)

Only log loss clips probabilities to [1e−12, 1−1e−12] for finite logarithms. InfoGap and Brier use the original probabilities. Thresholds and their one-sided limits are evaluated exactly. The factor 2 follows Theorem 4.1 and the proof of Theorem 5.1 in arXiv v2; the displayed estimator in Theorem 5.1 omits it. We retain the unscaled result too, and do not claim this is an author-confirmed correction.只有 log loss 把概率截到 [1e−12,1−1e−12] 以避免无穷对数；InfoGap 和 Brier 使用原始概率。精确计算全部阈值断点与单侧极限。系数 2 按 arXiv v2 定理 4.1 和定理 5.1 的证明，定理 5.1 展示式未写该系数；同时保留未缩放结果，这并非作者确认的勘误。
